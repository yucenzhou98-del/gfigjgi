## 專案儲存說明
本專案透過 Antigravity IDE 進行開發與管理，所有源程式碼檔案皆依標準網頁專案架構建立：
- `index.html`：網頁架構與故事內容 HTML
- `style.css`：網頁視覺樣式設計 CSS
- `script.js`：滑鼠懸停與點擊動態互動效果 JavaScript
- `README.md`：專案基本資訊與儲存說明文件

## 互動腳本 Prompt 指令
在專案開發最後階段下達之 Prompt 指令：
> 「請幫我規劃並製作這個幸運物網頁的動態互動效果，包含滑鼠懸停與點擊動畫。」
